An entry for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty: https://make.fun/c/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922

The program writes one job title to `/output/entry.txt`: "Chief Apology Officer for Self-Driving Cars" — a real-sounding corporate title for the human employed to stand at crosswalks and apologise on behalf of robot cars that cannot say sorry themselves.

## Run it

```sh
python3 main.py
```

This writes the title to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
